    Instructions & Troubleshooting

    How to Use

    1. Download the standalone HTML file above or host it locally.
    2. Open the saved MoonScout.html file in any browser.
    3. MoonScout will automatically test and pre-fill your gateway subnet.
    4. Tap Scout to sweep IPs .1 through .254 on port 7125.

    Moonraker CORS Configuration

    Ensure your printers' moonraker.conf accepts cross-origin requests:

    [authorization]
cors_domains:
    *
    How It Works (Privacy & Security)

    100% Client-Side & Private

    MoonScout runs entirely in your web browser. No analytics, tracking, external server calls, or network data ever leave your machine.

    Port 7125 Asynchronous Sweep

    When you click Scout, MoonScout sends light, non-blocking HTTP probes across addresses .1 through .254 targeted specifically at port 7125 (the standard Moonraker API port). Active instances return immediately and display in the list with a direct link to open Fluidd or Mainsail.
